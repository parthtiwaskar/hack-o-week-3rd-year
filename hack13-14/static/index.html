MODULE 02

The Bias–Variance Trade-off

Expected Generalization Error decomposes mathematically as: $$\mathbb{E}[\text{MSE}] = \text{Bias}^2 + \text{Variance} + \sigma^2_{\text{noise}}$$ Low complexity yields high bias (underfitting); high complexity yields high variance (overfitting).

MODULE 04

Regularization (L1 Lasso vs. L2 Ridge in Ensembles)

L1 (Lasso / reg_alpha) adds a penalty proportional to the absolute magnitude of weights ($|w|$), driving coefficients to zero for feature selection. L2 (Ridge / reg_lambda) penalizes squared magnitudes ($w^2$), smoothly shrinking weights to control variance.
