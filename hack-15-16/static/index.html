UNDER THE HOOD

How learning happens.

A loop, not a leap.
01 / FORWARD
→

Make a guess

Inputs travel forward, multiplied by weights and shifted by biases. An activation function decides what passes through.

X → ReLU(XW₁ + b₁) → σ(HW₂ + b₂)
02 / MEASURE
⌁

Measure the miss

Binary cross-entropy compares the predicted probability with the true answer. A bigger mismatch means a bigger loss.

L = −[y log(p) + (1−y) log(1−p)]
03 / BACKWARD
←

Learn from it

Backpropagation applies the chain rule to send the error backwards and figure out which weights contributed most.

∂L/∂W = ∂L/∂p · ∂p/∂z · ∂z/∂W
04 / UPDATE
↻

Take a better step

SGD nudges weights against the gradient. Adam tracks gradient averages to adjust each step as learning unfolds.

W ← W − η · gradient
